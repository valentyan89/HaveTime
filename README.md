# HaveTime - Умный календарь для Android

## Использование приложения

### День (Day View)
1. На экране "День" видна временная шкала всех задач дня
2. Нажмите на время для создания новой задачи
3. Нажмите на существующую задачу для редактирования

### Месяц (Month View)
1. Просмотрите всех месячный календарь
2. Клавиша на день для переключения на день этого дня
3. Используйте иконку года для просмотра всего года

### Карта (Map View)
1. Переключитесь на вид "Карта" в нижней навигации
2. Все задачи с местоположением отображаются маркерами
3. Клик на маркер открывает подробности задачи
4. Клик на карту создаёт новую задачу в этом месте

### Поиск
1. Используйте поле поиска в нижней части экрана
2. Введите название задачи для поиска по текущему дню

## Основные экраны

- **DayScreen** — просмотр и управление задачами по часам дня
- **MonthScreen** — месячный календарь с переходом на день
- **YearScreen** — просмотр всего года по месяцам
- **MapScreen** — карта с геолокированными задачами
- **AuthScreen** — экран аутентификации пользователя
- **AddActivityDialog** — диалог создания/редактирования задачи
